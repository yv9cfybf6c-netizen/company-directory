# ANOMALIES.md — странности в review.csv

Файл заявлен как «свежая выгрузка для той же базы». При разборе обнаружено
множество проблем. Ниже — полный список с указанием, **как обнаружено**.

---

## 1. Повреждённая кодировка (mojibake)

**Что:** имена и города в двух строках записаны «кракозябрами»:

| id        | name (как в файле)              | city (как в файле)          |
|-----------|---------------------------------|-----------------------------|
| c_001008  | РћРћРћ В«Р—Р°СЂСЏ РўРµС…В»     | РњРѕСЃРєРІР°                |
| c_001128  | РћРћРћ В«РўРµРјРї РњРµРґРёР°В» | РЎР°РЅРєС‚-РџРµС‚РµСЂР±СѓСЂРі |

**Как нашли:** поиск подстрок `Рћ`, `Р—`, `Рў`, `Рњ`, `РЎ` в полях name/city.
Декодирование `encode('cp1251').decode('utf-8')` даёт нормальный русский:
«ООО «Заря Тех»», «Москва» и т.д. Классическая двойная UTF-8/cp1251 ошибка.

## 2. Рейтинг вне допустимого диапазона

| id        | rating | проблема          |
|-----------|--------|-------------------|
| c_001122  | -3     | отрицательный     |
| c_001186  | 7.2    | > 5.0             |
| c_001010  | 4,5    | запятая вместо точки |
| ~21 строк | пусто / N/A | null              |

**Как нашли:** попытка `float(rating.replace(',','.'))` + проверка `0 ≤ x ≤ 5`.

---

## 3. reviews_count — мусорные значения

| id        | reviews_count | проблема        |
|-----------|---------------|-----------------|
| c_001116  | -10           | отрицательное   |
| c_001187  | много         | не число        |
| c_001079  | 45.5          | дробное         |

**Как нашли:** `int(float(...))` падает или даёт отрицательные/нецелые.

---

## 4. Города — опечатки, транслит, утечка адреса

| значение в файле              | что не так                          |
|-------------------------------|-------------------------------------|
| `Moscow`                      | английский вместо «Москва»          |
| `москва`                      | нижний регистр                      |
| `Москва `                     | trailing space                      |
| `Санкат-Петербург`            | опечатка (должно Санкт-)            |
| `ул. Советская, д. 89, офис 43` | **адрес попал в поле city**       |

**Как нашли:** `df['city'].unique()` + фильтр по латинице / `startswith('ул.')`.

---

## 5. Сдвиг колонок (column shift)

Строка `c_001015` (АО «Платформа»):

```
category = "Пермь"
city     = "ул. Советская, д. 89, офис 43"
address  = null
```

Очевидно, при выгрузке категория «съехала»: настоящее city=Пермь, address=ул. Советская…
**Как нашли:** category ∈ известных городов И city начинается с «ул.».

## 7. Сайты-заглушки / битые URL

| id        | site                        |
|-----------|-----------------------------|
| c_001132  | https://                    |
| c_001064  | нет сайта                   |
| c_001020  | htp://sintez-service-453.ru |

`shared-site.ru` — один и тот же placeholder у разных компаний.
**Как нашли:** точное совпадение / `startswith('htp')` / пустой path.

## 8. Дубликаты внутри review.csv

Три id встречаются **дважды** (в конце файла повторяются строки):

- c_001049 («Ритм Сервис»)
- c_001050 (ООО «Кварц Тех»)
- c_001075 (ООО «Восток Групп»)

**Как нашли:** `df[df.duplicated('id', keep=False)]`.

---

## 9. Пересечение с основной базой (page_*.json)

6 id уже есть в основной выгрузке (c_000xxx):

`c_000098`, `c_000246`, `c_000263`, `c_000425`, `c_000769`, `c_000851`

При наивной загрузке без `ON CONFLICT` получили бы дубли по PK.
**Как нашли:** `set(review.ids) & set(main.ids)`.

---

## 10. Странные id серии c_900xxx

6 записей с id `c_900006` … `c_900011` — вне основной нумерации c_000001–c_001000.
Имена без кавычек/ООО в необычном формате («АО Флагман Лаб», «Модуль Строй»).
Похоже на тестовые/ручные вставки.
**Как нашли:** `id.str.startswith('c_9')`.

---

## 11. Пустые хвостовые строки

Две полностью пустые строки в конце CSV (после дедупликации отбрасываются).
**Как нашли:** `df.dropna(how='all')` уменьшает 207 → 205.

---

## 12. Смешанные кавычки в name

`ООО "Ромашка"` — английские `"` вместо «ёлочек».
**Как нашли:** `'"' in name and '«' not in name`.

---

## Итог

Файл **нельзя** заливать «как есть». Минимум:

1. Починить mojibake.
2. Обнулить rating ∉ [0, 5] и reviews_count < 0 / «много».
3. Нормализовать города.
4. Исправить сдвиг колонок у c_001015.
5. Выкинуть заглушки phone/site.
6. Дедуплицировать.
7. `ON CONFLICT (id) DO NOTHING` (или DO UPDATE) при вставке.

Скрипт `scripts/load_review.py` делает пункты 1–7.
